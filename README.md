# Divisible by 3 – C Programming

## About the Project
This project is a simple C programming exercise. It asks the user to enter a number (N) and calculates the sum and count of all numbers divisible by 3 between 1 and N.

## Concepts Used
- Variables
- For loops
- If statements
- Modulo operator (%)
- Arithmetic operations
- printf() and scanf()

## Example Output
```text
Enter N: 10
Sum of numbers divisible by 3: 18
Count of numbers divisible by 3: 3
```

## How to Run
```bash
gcc divisible_by_3.c -o divisible_by_3
./divisible_by_3
```

## Language
C

Created for practicing basic C programming concepts.
